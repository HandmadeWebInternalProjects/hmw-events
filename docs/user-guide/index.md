# Handmade Web Event Manager — User Guide

Welcome. This guide shows you how to run events with the Handmade Web Event
Manager plugin: creating events, using templates to keep things consistent,
fine-tuning individual events, and managing the emails your attendees receive.

## How the pieces fit together

- **Events** are the classes, workshops, and sessions your clients book onto.
- **Event Templates** are reusable blueprints — they decide which fields
  appear, what the booking form asks for, and which options attendees can
  choose. Start every event from a template to save time.
- **Template Overrides** let you adjust one event without changing the
  template everyone else uses.
- **Email Templates** control the automatic emails sent around a booking —
  confirmations, reminders, receipts, and more.

## The guide

1. [Adding Events](adding-events.md) — create an event, set dates, prices and
   capacity, and use recurring events for repeating sessions.
2. [Event Templates](event-templates.md) — build and edit your templates.
3. [Assigning Templates](assigning-templates.md) — create events from a
   template and re-apply a template to events that already exist.
4. [Overriding Templates](overriding-templates.md) — tweak a single event's
   fields and booking form.
5. [Email Templates](email-templates.md) — edit the automatic emails and
   check the email queue.

## Where to find things in WordPress

| Menu item | What it does |
|---|---|
| **Events** | See, add, and edit your events |
| **Events → Calendar** | A month-view calendar of all your sessions |
| **Events → Delivery Modes** | Manage how events run — In Person, Online, Hybrid — and upload their card icons |
| **Handmade Web Event Manager → Event Templates** | Build and edit templates |
| **Handmade Web Event Manager → Email Templates** | Edit automatic emails |
| **Handmade Web Event Manager → Email Queue** | See what emails were sent or are waiting |
| **Handmade Web Event Manager → Reporting** | Bookings and payment reports |
| **Handmade Web Event Manager → Coupons** | Discount codes clients can use at booking |
| **Handmade Web Event Manager → Settings** | Stripe keys and plugin settings |
