# Screenshots for the User Guide

Drop the screenshots listed below into this folder. The guide references
them with relative paths (`images/...`), so as long as they live here with
these exact filenames, the guide renders anywhere the plugin is installed.

Use PNG format, captured at the default WordPress admin zoom. Aim to show
the relevant part of the screen clearly; full-window shots are fine.
